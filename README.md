# Atividade Prática - JavaScript, API REST e Vue.js

## Sobre o projeto

Este repositório contém as atividades desenvolvidas durante a disciplina, abordando conceitos de JavaScript, algoritmos de ordenação, manipulação do DOM, consumo de APIs REST e utilização do framework Vue.js.

O projeto foi dividido em três partes principais:

### Parte 1 - Ordenação de Números

Aplicação para cadastro e manipulação de números, permitindo:

* Adicionar números à lista
* Misturar os valores aleatoriamente
* Ordenar utilizando diferentes algoritmos:

  * Bubble Sort
  * Selection Sort
  * Quick Sort
* Exibir a quantidade de números cadastrados

### Parte 2 - Catálogo de Receitas

Aplicação desenvolvida com HTML, CSS e Bootstrap para exibição de receitas.

Funcionalidades:

* Exibição das receitas em formato de cards
* Imagens ilustrativas
* Lista de ingredientes
* Modal para visualização detalhada da receita
* Interface responsiva e moderna

### Parte 3 - Usuários via API REST e Vue.js

Aplicação desenvolvida utilizando Vue.js para consumo de dados externos.

Funcionalidades:

* Consumo da API ReqRes utilizando Fetch API
* Exibição dinâmica de usuários
* Utilização de diretivas Vue.js (`v-for`)
* Cards responsivos com Bootstrap
* Modal de detalhes do usuário
* Interface moderna com efeitos visuais

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* Bootstrap 5
* Vue.js 2
* Fetch API
* Git e GitHub

## Observação

Os dados dos usuários são fornecidos pela API pública ReqRes.

Em alguns navegadores, as imagens dos usuários podem ser bloqueadas devido a políticas de segurança relacionadas a CORS (Cross-Origin Resource Policy), embora os dados da API sejam carregados normalmente.
